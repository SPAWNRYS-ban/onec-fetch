# Запуск внутри 1С:Предприятия 8.3

1. Создай внешнюю обработку с основной управляемой формой.
2. Добавь реквизит формы `Вывод` — строка неограниченной длины. Свяжи его с многострочным полем «Только просмотр», выбери моноширинный шрифт.
3. Вставь [Форма1С.bsl](Форма1С.bsl) в модуль формы.
4. Назначь обработчик события `ПриОткрытии`. Добавь команду и кнопку `Обновить` с обработчиком `Обновить`.
5. Сохрани `.epf` и открой через «Файл → Открыть» в 1С:Предприятии.

ОС и оборудование собираются на клиенте, конфигурация и пользователь базы — на сервере. В веб-клиенте сведения ограничены. Это исходник формы, не готовый `.epf`; запуск в платформе 1С не проверен.
