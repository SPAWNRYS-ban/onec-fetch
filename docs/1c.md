# Запуск внутри 1С:Предприятия 8.3

1. Создайте внешнюю обработку с основной управляемой формой.
2. Добавьте реквизит формы `Вывод` — строка неограниченной длины. Свяжите его с многострочным полем «Только просмотр», выберите моноширинный шрифт.
3. Вставьте [Форма1С.bsl](Форма1С.bsl) в модуль формы.
4. Назначьте обработчик события `ПриОткрытии`. Добавьте команду и кнопку `Обновить` с обработчиком `Обновить`.
5. Сохраните `.epf` и откройте через «Файл → Открыть» в 1С:Предприятии.

ОС и оборудование собираются на клиенте, конфигурация и пользователь базы — на сервере. В веб-клиенте сведения ограничены. Это исходник формы, не готовый `.epf`; запуск в платформе 1С не проверен.
