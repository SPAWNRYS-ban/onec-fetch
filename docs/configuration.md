# Конфигурация и JSON

Вы можете задать порядок модулей через `-s CPU:GPU:Memory` или загрузить JSON/JSONC через `-c config/example.jsonc`. JSONC поддерживает `//`, `/* */` и завершающие запятые. Автоматическая загрузка конфигурации fastfetch не выполняется. Это собственный формат onec-fetch; весь набор опций fastfetch не поддерживается.

```jsonc
{
  "logo": "auto",
  "timeout": 3000,
  "interval": 200,
  "allowNetwork": false,
  "modules": [
    "Title", "OS", "CPU", "Memory",
    {"type": "Memory", "key": "RAM", "format": "{value}; всего {total} байт"},
    {"type": "Custom", "key": "Примечание", "text": "Ваш текст"},
  ],
}
```

Модуль задаётся строкой или объектом с `type`. `key` меняет подпись; `format` поддерживает `{value}` и простые поля объекта `data`, например `{name}` или `{total}`. Единицы числовых полей остаются исходными. Массивы устройств представлены через `{value}`; вложенные шаблоны fastfetch не поддерживаются. CLI имеет приоритет над конфигурацией.

`--all` выбирает все 76 модулей. `--debug` показывает причины недоступности в текстовом выводе; JSON содержит их всегда. `--timeout=3000` ограничивает время отдельной команды/HTTP-запроса, `--interval=200` задаёт общий интервал Linux-замера CPUUsage/DiskIO/NetIO/Top. Допустимый диапазон — 50–60000 мс. Windows использует производительные счётчики самой ОС. Команды кешируются в пределах одного запуска; суммарное время `--all` может превышать один таймаут.

В обычном запуске нет обращений к внешним сервисам. Для PublicIp и Weather задайте `--allow-network` или `"allowNetwork": true`. Источники: `api.ipify.org` и `wttr.in`; для Weather доступен `--location=Москва` / поле `location`. Без места wttr.in использует IP запроса. Эти сервисы не проверены в локальном приёмочном прогоне.

Command выполняет только явно заданную команду через shell (`/bin/sh` или `cmd.exe`):

```sh
./onec-fetch -s Command --command='printf "Ваш текст\n"'
```

В конфигурации используйте объект `{"type":"Command","command":"..."}`. Без команды модуль отключён. Обнаруженные имена устройств передаются системным утилитам отдельными аргументами. У процессов раздельные stdout/stderr, ограничение вывода 4 MiB символов и остановка дерева при таймауте.

`--width=100` задаёт ширину текстового вывода; длинные значения переносятся, в узком окне логотип скрывается. `NO_COLOR` отключает ANSI; `--color` включает его явно. Палитра содержит 16 цветов.

## JSON

`--json` / `--format=json` возвращают объект с `schemaVersion: 2`, прежними плоскими ключами и массивом `modules` в выбранном порядке:

```json
{"schemaVersion":2,"modules":[{"type":"Memory","key":"Память","status":"ok","source":"/proc/meminfo","data":{"total":8178073600,"available":2000000000,"used":6178073600,"percentage":75.54},"display":"5.75 GiB / 7.62 GiB (76%)","error":""}]}
```

Пример сокращён и содержит иллюстративные значения. Каждый результат имеет `type`, `key`, `status`, `source`, `data`, `display`, `error`. Статусы: `ok`, `unsupported`, `unavailable`, `permission_denied`, `timeout`, `error`, `disabled`. `ok` с пустым массивом означает установленное отсутствие устройств. Частично доступный источник может иметь `ok` и незаполненные необязательные поля; наличие имени модуля не гарантирует наличие каждого поля.

Размеры передаются в байтах, частоты CPU/GPU — в герцах, частота экрана — в герцах, uptime/интервал — в секундах. Сырые WMI/API-объекты сохраняют единицы и названия источника; некоторые утилиты возвращают `output`/`raw` вместо разобранных аппаратных полей. Недопустимые для структуры 1С символы в именах входного JSON заменяются `_`.

`--json=legacy` возвращает только прежние плоские ключи; текст значений теперь отражает расширенный вывод. Данные невыбранных аппаратных модулей не собираются и соответствующие строки остаются пустыми. JSON onec-fetch не является точной копией схемы fastfetch.

## Проверка и сборка

```sh
python3 tests/test_modules.py
python3 tests/test_logos.py
python3 tests/test_parity.py       # если установлен fastfetch
python3 scripts/package.py
python3 tests/test_release.py
```

Основной код — `onec-fetch.os` и `lib/*.os`. `helpers/windows.ps1` предоставляет доступ к системным Windows API; fastfetch не вызывается программой и не включён в архивы. Все расчёты Linux, общая обработка, выбор источников, конфигурация, JSON и оформление выполняются на языке 1С. Форма из `docs/1c.md` остаётся отдельным базовым примером, без модульного движка OneScript.
