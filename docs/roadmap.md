# Планы развития

## Транслятор части языка 1С в C

Идея сохранена для будущего исследования. Сейчас используется OneScript с отдельными модулями в режиме `#native`.

Цель — сохранить основную логику onec-fetch в исходниках на языке 1С и заранее преобразовывать используемую часть языка в C. GCC или Clang будет собирать самостоятельные бинарные файлы для целевой ОС, без запуска OneScript/.NET.

Первый прототип должен поддерживать только необходимые программе конструкции: функции и процедуры, условия, циклы, строки, числа и коллекции. Нужна небольшая библиотека совместимости для файлов, процессов, JSON и системных API. Полная совместимость с платформой 1С:Предприятие в начальную цель не входит.

Перед расширением прототипа необходимо сравнить корректность и полное время запуска с текущей версией: короткая сводка, выбранные модули и `--all`. Также необходимо проверить Unicode, обработку ошибок, таймауты процессов, Linux/Windows и упаковку `.deb` / `.pkg.tar.zst`.

Решение о реализации пока не принято. Готового собственного транслятора в проекте нет.
